# Wellbeing agents

Three agents that share one realm and one kit: a nutritionist, a fitness coach and a dog trainer. Each one keeps
to its own scope and hands the rest to its siblings. Each answers only from its own cited knowledge cards and its
memory on this computer, never from the web. When one of them needs something it does not know, it asks Louise,
the research librarian, to look it up and learns from her book when it lands. The shared kit is in `kit/`
(`kit/CONTRACT.md` lists every command an agent may rely on); each agent lives in `agents/<key>/`.

This README is finished in a later row: the realm, how to open each agent, and the install notes.
